# Third-party notices

DNS Switcher Pro utilizza dipendenze open source distribuite con le rispettive
licenze. Consultare i file `package-lock.json` e i metadata dei pacchetti per i
testi completi.

- Python: FastAPI, Uvicorn, HTTPX, BeautifulSoup4, keyring, pywebview e Playwright
  (licenze dichiarate dai rispettivi progetti; compatibilità documentata nei loro
  pacchetti installati).
- Frontend: React, React DOM, Vite, TypeScript, Tailwind CSS, Autoprefixer,
  Lucide React, Framer Motion, TanStack Query, React Hook Form e Zod.

Il progetto DNS Switcher Pro è distribuito secondo GPL-3.0; le dipendenze restano
di proprietà dei rispettivi autori e mantengono le proprie licenze.
